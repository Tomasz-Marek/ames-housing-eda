# Ames Housing EDA

This project focuses on exploratory data analysis (EDA) of the Ames Housing dataset.

## Goals
- Understand data structure
- Analyze distributions of variables
- Detect missing values and outliers
- Identify relationships between features and house prices

## Tools
- Python
- pandas
- numpy
- matplotlib
- seaborn
- Jupyter Notebook

## Project Structure
- `data/` – raw and processed data
- `notebooks/` – analysis notebooks
- `reports/` – visualizations and results
